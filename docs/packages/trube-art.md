# Trube Art (`@intuitui-labs/trube-art`)

> **Living light surfaces, tactile organic shaders, and generative visual textures for React Native and Skia.**

---

## 🌟 Key Capabilities

* 🌅 **Living Light Optics**: Physics-informed lighting gradients that simulate biological and optical diffusion directly on canvas.
* ⚡ **Hardware Accelerated**: Compiles directly down to Skia Shader Language (SKSL) executed on native GPU pipelines via Nitro/JSI.
* 🎛️ **Responsive to Somatic Touch**: Dynamic parameters modulating fluid displacement based on touch velocity and gesture pressure.

---

```bash
pnpm add @intuitui-labs/trube-art @shopify/react-native-skia
```
